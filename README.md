# Script-Controlled ACL – Restrict Record Access Based on Field Value

## Project Description
This project demonstrates script-controlled Access Control Lists (ACLs)
in ServiceNow to restrict record-level access based on user roles and
record field values.

## Project Components
1. Creation of Users and Roles
2. Table Creation
3. READ ACL
4. CREATE ACL
5. WRITE ACL
6. DELETE ACL

## Verification
The ACLs were tested to verify access permissions for the required users
and roles.
